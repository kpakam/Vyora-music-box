# VYORA – Music Without Borders.

## IMPORTANT: How to run

Do **NOT** double-click `index.html`. That will not work reliably.

### Option A – Start script

**Mac / Linux / Termux:**
```bash
chmod +x start.sh
./start.sh
```

**Windows:**
```
double-click start.bat
```
(or run it from Command Prompt)

### Option B – Manual server

```bash
cd folder-with-index.html
python3 -m http.server 3456
```

Then open in your browser:

**http://127.0.0.1:3456**

### Requirements

- Python 3 (usually preinstalled on Mac/Linux; on Windows install from python.org)
- A modern browser (Chrome, Firefox, Edge, Safari)

### Demo login

Any email + password. Use an email containing `admin` for the Admin dashboard.

### Audio

Demo tracks use free SoundHelix sample MP3s (requires internet for audio).
